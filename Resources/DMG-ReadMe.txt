TP Classroom for Mac
====================

TEACHER'S MAC
  Double-click "TP Classroom" right here and click "Move to Applications".
  (No admin password? That's fine: it goes into the Applications folder inside your home folder.)
  Choose a class code. Use the same code on every student computer (Mac or Windows).

STUDENT MACS
  Open "TP Classroom Student" (right here in this window is fine), type the class code and an
  admin PIN, then click "Install for All Users on This Mac…" and enter an administrator password.
  Then, once per Mac, go to System Settings → Privacy & Security and turn on TP Classroom Student in:
    • Screen Recording   (so the teacher can see the screen)
    • Accessibility      (so the teacher can help with the mouse and keyboard)
  Log out and back in.

IF MACOS SAYS IT CAN'T OPEN THE APP
  Open System Settings → Privacy & Security, scroll down and click "Open Anyway"
  (or right-click the app → Open on older macOS).

Computers find each other by themselves on the same network. No internet or IP addresses needed.
Students always see the eye icon in the menu bar, and a banner while the teacher is watching or helping.
